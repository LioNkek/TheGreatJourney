## 📖 О проекте
Адаптивное веб-приложение для планирования путешествий. В проекте реализована работа с DOM, обработка событий, архитектура приложения на чистом JavaScript (ES6+), а также сборка через Webpack.

## 🛠 Стек технологий
- **Разметка:** HTML5 (семантическая верстка)
- **Стилизация:** CSS3 (адаптивность, flexbox)
- **Скрипты:** JavaScript (ES6+, модули, работа с DOM, обработка событий)
- **Сборка:** Webpack (оптимизация, сборка бандла)
- **Инструменты:** Git, npm, ESLint
